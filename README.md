# MiniBug-RL

MiniBug-RL trains a tiny code model to repair Python functions using reinforcement learning from hidden unit-test rewards. The implementation and measured results are being built incrementally; commands and claims will be promoted here only after they are exercised end to end.

The project uses [uv](https://docs.astral.sh/uv/) for a locked Python environment and follows the public [TRL GRPO](https://huggingface.co/docs/trl/main/en/grpo_trainer) interface.
